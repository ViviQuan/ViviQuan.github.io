# 🔬 Research Experience {#research}

**Missing-Modality-Aware Visual Question Answering for Remote Sensing Multimodal Large Models**
*07/2026 - Present · Research Assistant, The Chinese University of Hong Kong, Shenzhen*
Supervised by Prof. Qingyu Li
- Developed a programmatic pipeline for constructing a multimodal remote sensing VQA benchmark with missing-modality configurations and rule-based quality control.
- Designed missing-modality-aware modules to improve model robustness under incomplete multimodal inputs.
- Developed a fine-tuning and evaluation pipeline for adapting Qwen3-VL under complete- and missing-modality settings.

**Subspace-aware Angular-margin Gaussian Ensemble for Rehearsal-Free Class-Incremental Learning**
*09/2025 - Present · Xidian University*
Supervised by Prof. Tianyang Zhang
- Proposed a rehearsal-free class-incremental learning framework on frozen ViT using task-specific adapters in dedicated subspaces for knowledge isolation.
- Designed a sine-guided angular margin optimization with adaptive hard-negative constraints for high-similarity remote sensing categories.
- Introduced a variance-weighted Gaussian inference module with per-subspace Z-score calibration for reliable cross-task prediction.

**HiMoE: Hierarchical Mixture-of-Experts Dynamic Fusion for Multimodal Image Segmentation**
*04/2025 - 03/2026 · Xidian University*
Supervised by Prof. Xueli Geng
- Proposed the HiMoE dynamic fusion framework achieving SOTA segmentation performance with only 2.18M parameters.
- Designed a Gated ConvMamba Block hybrid encoder integrating CNN local feature extraction and Mamba long-range dependency modeling.
- Proposed a Spatial-Frequency Fusion (SFFusion) module combining spatial saliency and frequency spectral features for adaptive cross-modal fusion.
- Built a HiMoE decoder with hierarchical pixel-wise gating, validated against 10+ SOTA methods on 4 remote sensing benchmarks.

**Temperature-sensitive Reconfigurable Antenna Sensor Based on Dual-patch Antenna Form**
*11/2024 - 05/2026 · Xidian University*
Supervised by Prof. Nan Zhao
- Simulated and analyzed microstrip and array antennas, comparing theoretical calculations with simulation results.
- Designed an innovative dual-patch antenna structure based on bimetallic strip materials for improved antenna performance.
- Conducted HFSS simulation and parameter optimization across different frequency bands and polarization conditions.

**Research on Human Action Recognition Integrating Visual SLAM and Dual-Stream CNN**
*12/2024 - 01/2025 · NC State University*
Supervised by Prof. Kevin Han
- Proposed a vision-based solution leveraging Visual SLAM and CNN to identify unsafe worker behaviors from helmet-mounted cameras.
- Designed a two-stream 1-D CNN model for body action recognition and head gesture recognition.
- Achieved over 80% accuracy with real-time performance (0.56s average latency).
